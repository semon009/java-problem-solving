# Java OOP - Shape and Rectangle Inheritance

A simple Java program demonstrating Object-Oriented Programming (OOP) concepts, specifically **Inheritance**.

---

## 📝 Problem Statement

Create a base class called `Shape` that holds the shape's name. Then create a derived class called `Rectangle` that inherits from `Shape`. 

The `Rectangle` class should:
- Take the rectangle's `length` and `width` as parameters in its constructor, along with the shape's `name`.
- Include a method to calculate the rectangle's area.

In the `Main` class:
- Create an instance of the `Rectangle` class using user inputs (name, length, width).
- Print the rectangle's name and its calculated area.
