# Currency Enum (ISO 4217)

A Java implementation of a non-public `Currency` enum containing select standard ISO 4217 currency codes.

## Included Currency Codes

* **USD** - United States dollar
* **EUR** - Euro
* **GBP** - Pound sterling
* **RUB** - Russian ruble
* **UAH** - Ukrainian hryvnia
* **KZT** - Kazakhstani tenge
* **CAD** - Canadian dollar
* **JPY** - Japanese yen
* **CNY** - Chinese yuan

## Usage

```java
Currency userCurrency = Currency.USD;
