# Polygon & Square Area Calculator (Java OOP)

## 📌 Description
This program demonstrates the core Object-Oriented Programming (OOP) concept of **Inheritance** in Java.

A base class `Polygon` manages the side length properties, while a derived class `Square` inherits from `Polygon` and adds functionality to compute the area of the square.

---

## 🧠 Concepts Covered
* **Inheritance:** `Square extends Polygon`
* **Encapsulation:** Private fields accessed via `getter` and `setter` methods
* **Static Inner Classes**
* **User Input Handling:** `java.util.Scanner`

---

## 📥 Input & Output Format

### Input
* A single integer representing the side length of the square.

### Output
* A single integer representing the calculated area ($side \times side$).

---

## 🧪 Sample Cases

### Sample Case 1
* **Input:** `4`
* **Output:** `16`

### Sample Case 2
* **Input:** `5`
* **Output:** `25`
