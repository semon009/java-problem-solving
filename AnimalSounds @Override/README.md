# Animal Sounds Implementation (Java Inheritance)

## Overview
A simple Java exercise demonstrating foundational Object-Oriented Programming (OOP) principles: **Inheritance** and **Method Overriding**.

## Problem Statement
- Create a base class `Animal` with a `speak()` method returning `"Animal sound..."`.
- Create a derived class `Dog` that overrides `speak()` to return `"Bark!"`.
- In `Main`, create a `Dog` object named `fido` and print the output of `fido.speak()`.

## Output
```text
Bark!
