# Days of the Week Enum

A Java program demonstrating a package-private `DayOfWeek` enum and iterating over its values using `DayOfWeek.values()`.

## Features

* Non-public `DayOfWeek` enum containing all seven days of the week in uppercase.
* Includes a `Main` class to test and display all enum constants.

## Output

```text
SUNDAY
MONDAY
TUESDAY
WEDNESDAY
THURSDAY
